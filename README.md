# daily-notes

自分用の簡易メモを、複数の端末（スマホ・PC等）間で同期して見るための個人ツールです。

## 使い方

1. ページを開き、アクセスパスワードを入力
2. 初回のみ、同期キー（自分の全端末で共通の文字列）を設定
3. メモを追加すると、同じ同期キーを設定した他の端末にも自動反映されます

## メモ

- メモは送信から一定期間で自動的に削除されます
- 暗号化キーを忘れると過去のメモは復号できません（設計上、復元不可）

## 技術構成

- フロントエンド: 素のHTML/JS
- バックエンド: Supabase（DB / Realtime同期 / 認証）
- ホスティング: GitHub Pages
